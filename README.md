# PC Stats

**Статистика персонажа для Arizona RP** · MoonLoader · SA-MP

Современный помощник для отслеживания прогресса, финансов, налогов и личных охранников — всё в одном удобном меню.

---

## Возможности

### Персонаж
- Подробная статистика персонажа с сервера
- Таймер времени в игре
- Автообновление данных по интервалу

### Бой
- Боевые показатели и прогресс
- Наглядные карточки и подсветка важных значений

### Финансы
- Общий баланс: наличные, банк, депозит, валюты
- Курсы **VC$ / BTC / AARP / AZ-Coin** и др.
- Обновление курсов **с телефона** (CEF) или с wiki
- Ручной ввод курсов при необходимости
- Раздел **Охранник** — призыв, скрытие, кормление (логика AIS 2.0.6)

### Налоги
- Ручная и **автооплата** налогов
- Оплата при входе в игру (с умной защитой от повторной оплаты)
- Отель / связанные сценарии оплаты
- Команда `/paytax`

### Настройки
- Цвета и темы интерфейса
- Размер окна и шрифта (удобно на PC и mobile)
- Команда открытия меню (по умолчанию `/sw`)
- Уведомления (тосты + чат)
- Кнопка меню на экране

### О скрипте
- Версия и информация
- Ссылки на Telegram / Discord
- **Самообновление** с GitHub (`/pcsupdate`)

## Установка

1. Установите [MoonLoader](https://blast.hk/moonloader/) для SA-MP.
2. Скопируйте `PCStats.lua` в папку:
   ```
   GTA San Andreas / moonloader /
   ```
3. Запустите игру и зайдите на сервер **Arizona RP**.
4. В чате появится сообщение вида:
   ```
   [MSW v1.8.x] PC Stats | Cmd: /sw
   ```
5. Откройте меню командой **`/sw`** (или своей, если меняли в настройках).

### Зависимости
| Модуль | Назначение |
|--------|------------|
| `mimgui` | Интерфейс |
| `samp.events` / `lib.samp.events` | События SA-MP |
| `inicfg` | Конфиг |
| `encoding` | CP1251 ↔ UTF-8 |

Обычно они уже есть в типичной сборке MoonLoader + SAMPFUNCS / плагинах Arizona.

## Команды

| Команда | Описание |
|---------|----------|
| `/sw` | Открыть / закрыть меню (или ваша команда из настроек) |
| `/paytax` | Оплатить налоги |
| `/pcsupdate` | Проверить обновление на GitHub |
| `/pcsupdate install` | Скачать и установить обновление |

Управление охранником — **из меню** (Финансы → Охранник), без лишних чат-команд.

## Самообновление

Скрипт сверяет версию с репозиторием:

- **GitHub:** `Market88888/CR-Helpers`
- Файлы: `manifest.json` + `PCStats.lua`

Если на GitHub версия **новее** — в чат придёт напоминание, а в разделе «О скрипте» появится кнопка установки.

```bash
/pcsupdate          # только проверка
/pcsupdate install  # скачать и заменить файл
```

После установки скрипт перезагрузится сам.

## Конфиг

Настройки сохраняются через **inicfg** в рабочей папке MoonLoader.  
Данные охранников (AIS):  

```
moonloader/config/Auto-Interaction Securities.json
```

Можно безопасно удалить конфиг — скрипт создаст значения по умолчанию.

---

## Безопасность и стабильность

- Критичные вызовы обёрнуты в `pcall`
- Ошибки пишутся в `moonloader.log`
- Watchdog для «залипшего» телефона при оплате налогов / курсах
- Не используется `os.execute` / `loadstring` для обновлений
- Атомарная замена файла при апдейте
